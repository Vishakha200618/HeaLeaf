# 🌱 Healeaf – Student Well-Being Analytics Dashboard

> **Understand your patterns. Improve your well-being.**

Healeaf is a **data-driven student well-being analytics dashboard** built to explore how academic and lifestyle factors such as **sleep, study time, screen time, academic pressure, mood, stress, anxiety, and meditation** are associated with overall student well-being.

The project uses data analysis, visualization, and machine learning techniques to transform raw student data into meaningful and easy-to-understand insights.

---

## 🎯 Project Objective

Students often experience academic pressure and lifestyle changes that can affect their overall well-being.

The objective of Healeaf is to:

* Analyze student lifestyle and academic patterns
* Visualize factors related to stress and well-being
* Calculate and explore a **Mental Health Score**
* Identify relationships between different student factors
* Present insights through an interactive dashboard

> **Note:** Healeaf is an educational data analytics project and is not intended for medical diagnosis or treatment.

## 📊 Dataset

The dataset contains student-related academic, lifestyle, and well-being information.

Some of the important variables include:

* Study Time
* Sleep Time
* Screen Time
* Academic Pressure
* Mood
* Stress
* Anxiety
* Meditation
* Mental Health Score

The data is analyzed to understand patterns and relationships between these factors.

---

## 🤖 Machine Learning

Healeaf uses **Linear Regression** to explore relationships between selected student-related factors and the Mental Health Score.

The machine learning component is used for **analytical exploration** and understanding patterns in the dataset rather than for medical prediction or diagnosis.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Vishakha200618/Healeaf.git
```

### 2. Navigate to the project folder

```bash
cd Healeaf
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run dashboard/app.py
```

The dashboard will open in your browser, usually at:

```text
http://localhost:8501
```
